# PaisaTrack - Expense Tracker

PaisaTrack is a simple and colourful web app that helps you see where your money
comes from and where it goes. It was made as a project for the Web Technologies subject.

## Features
- Add income and expenses with title, amount, category and date
- Edit or delete any single transaction, or delete all data
- Summary cards for balance, total income and total expense
- Income sources section (where your income comes from, and how much)
- Spending chart by category
- Monthly budget with a progress bar (turns yellow, then red)
- Search and filter by type, category and month
- Download all transactions as a CSV file
- Dark mode and smooth animations
- Data is saved in the browser, so it stays after closing the page

## Technologies Used
- HTML - page structure
- CSS - design and animations
- JavaScript - logic and saving data (localStorage)

## How to Run
1. Download or clone this repository
2. Keep `index.html`, `style.css` and `script.js` in the same folder
3. Open `index.html` in any browser

No installation or internet is needed.
